### 二次型正交变换：两次对角化的特征值顺序要对齐，`Q` 不唯一

**类别**：knowledge_gap
**优先级**：medium
**状态**：pending
**范围**：线代 / 二次型（`la-c12-comprehensive-solution-011`）

**摘要**：求使 $Q^{\mathsf T}AQ=B$ 的正交阵 $Q$，做法是分别正交对角化：$Q_1^{\mathsf T}AQ_1=\Lambda_1$、$Q_2^{\mathsf T}BQ_2=\Lambda_2$，**只有 $\Lambda_1=\Lambda_2$（两边的列按特征值一一对齐）**才有 $Q=Q_1Q_2^{\mathsf T}$ 满足 $Q^{\mathsf T}AQ=B$（$Q$ 正交）。同组特征向量可换序换号，所以 $Q$ 不唯一。

**详情**：
- 本题 $A=[[1,0,0],[0,2,1],[0,1,2]]$、$B=[[2,0,-1],[0,1,0],[-1,0,2]]$，特征值都是 $1,1,3$。
- 取 $Q_1$ 的列 = $A$ 的 $\lambda=1$ 特征向量 $(1,0,0),(0,1,-1)$ 与 $\lambda=3$ 的 $(0,1,1)$，$Q_2$ 的列 = $B$ 的 $\lambda=1$ 的 $(0,1,0),(1,0,1)$ 与 $\lambda=3$ 的 $(-1,0,1)$，得 $Q=Q_1Q_2^{\mathsf T}=[[0,1,0],[1,0,0],[0,0,-1]]$——按题中 $f$ 与 $g$ 的系数核验 $Q^{\mathsf T}AQ$ 严格等于 $B$，$Q$ 正交。
- 答案卷给的 $[[0,1,0],[0,0,1],[-1,0,0]]$ 满足同一等式，是同一批列的另一种排列，两者都对：**别把答案卷的列序当唯一标准**。

**下次做法**：自检用 $Q^{\mathsf T}AQ=B$（等价 $AQ=QB$）加 $Q^{\mathsf T}Q=I$，不要与答案卷逐元素比对；写 $Q_1$、$Q_2$ 时每列旁边标清对应的特征值，顺序不一致就算错。

### 用户提供的解析是草稿不是权威：写入事实源前先验算

**类别**：correction
**优先级**：high
**状态**：pending
**范围**：880 答案卷解析替换流程 / 用户供稿

**摘要**：把用户贴来的解析沉淀进 `question-index.json` 时，长期是「整理格式即写入」的转录模式——本次用户给的错解反例 $f(x,y)=x^{2}+y^{2}+\sqrt{x^{2}+y^{2}}$ **不满足题设**（$\frac{f}{x^{2}+y^{2}}=1+\frac{1}{\sqrt{x^{2}+y^{2}}}\to+\infty\ne 1$），照抄进卷面会被阅卷人反手扣分。用户供稿里的**数学论证与反例**要当草稿验算，只有格式与措辞才照排。

**详情**：
- 事实：Q6 题设为 $\lim\frac{f}{e^{x^{2}+y^{2}}-1}=1$ 且 $f$ 连续。用户反例的比值极限是 $+\infty$，前提就不成立；换成合法反例 $f=(x^{2}+y^{2})(1+x\sin\frac1x)$（连续 ✓、比值 $\to1$ ✓，但 $f''_{xx}(0,0)=\lim(2+3x\sin\frac1x-\cos\frac1x)$ 振荡不存在 ⟹ $AC-B^{2}$ 前提崩塌）。
- 顺带校准了一处考点表述：题设其实**能**推出 $\nabla f(0,0)=(0,0)$（$|f|\leqslant C(x^{2}+y^{2})=o(\sqrt{x^{2}+y^{2}})$），缺的**不是一阶而是二阶**——「不能用 $AC-B^{2}$」的准确理由在此，说成「偏导可能不存在」是过头了。
- 根因：这类任务的动作是「整理排版 + 走事实源管道」，全部检验都落在**格式**（`$$` 配对、定界符、控制字符），没有任何一道手续问「这段数学对不对」——转录模式下供稿被默认当权威。

**下次做法**：用户供稿里凡出现**反例、构造、特例、推导链**，写入前逐条对题设验算（反例要与**全部**已知条件对表）；发现错误就换合法构造，并在回复里明确说明改了什么、为什么——不静默照抄，也不静默改掉。

- **首次应用（本日第 8 题）**：用户给的推导链（$F''=f'\Rightarrow$ 单侧导数定义 $\Rightarrow$ 分子分母定号 $\Rightarrow$ 保号性）逐条对题设验算后**通过**，未作任何改动即写入。规则的价值不只是逮错，也是「验过了、可以照排」的凭据——它把「转录」变成「复核」。

### 证明「只改了目标题块」用公共前缀/后缀定位，不用行 diff

**类别**：best_practice
**优先级**：high
**状态**：pending
**范围**：880 答案卷 / 聚合事实源的改动定位

**摘要**：要证明「整份文件里只有目标那块变了」，正确工具是算**公共前缀行数 + 公共后缀行数**：两边夹出的区间就是唯一的改动区间，再断言它落在目标块的行号范围内。行 diff 在缩进 JSON 里会被一处长度变化放大成全场错位，在答案卷里会被上百行解析噪声盖住结论——两者都答不了「别处有没有动过」。

**详情**：
- 事实：本次替换卷子-04 第 8 题解析，`--rebuild` 后答案卷 680 → 766 行。公共前缀 357 行、公共后缀 322 行，改动区间 = 新 358..444 / 旧 358..358，正好是「旧的单行反证法 → 新的 87 行解析」，且 358 行之前、445 行之后逐字节一致。
- 中途自造过一次假警报：拿**手写**的 0-based 边界去切尾段比对，得到「后段一致: False」。改成由公共后缀**算出**边界就干净了——边界要算法给出，不要手写行号。

**下次做法**：改单块内容的核验固定输出三行——`公共前缀行数 / 公共后缀行数 / 改动区间`，并断言改动区间 ⊆ 目标块行范围；边界一律计算得出。
