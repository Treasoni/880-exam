## 2026-09-02

### obsidian-markdown：重复题号使用了过短锚点

**错误**：修复答案卷时先用 `**2.**` 定位，误命中了选择题的第 2 题，而不是解答题的第 2 题；后续断言及时阻止了错误写入。

**触发场景**：同一答案卷中多个章节都从第 1 题重新编号，直接按题号查找不唯一。

**根因**：忽略了答案卷编辑规则中“章节标题 + 完整题干”的唯一锚点要求。

**修复**：改用 `## 三、解答题`、完整题干和相邻题目边界定位后再替换。

**预防措施**：
- 修改重复题号时，先限定章节范围，再断言完整题干唯一出现。
- 写入前后检查题目数量、顺序和答案与题目相邻关系未改变。

## 2026-09-03

### 复习消息：独立公式使用了不稳定的定界符

**错误**：给用户发送下一题时，独立公式使用 `\[...\]`，用户反馈题目渲染失败。

**触发场景**：880 错题复习对话中直接输出带公式的下一道题。

**根因**：忽略 `.learnings/RULES.md` 中独立公式统一使用 `$$...$$` 的可迁移规则。

**修复**：改用 `$$...$$` 重新发送题目，用户可正常阅读。

**预防措施**：
- 面向 Obsidian 或需要稳定渲染的复习消息，独立公式一律使用成对的 `$$...$$`。
- 发送前检查公式定界符成对。

### 880-analysis：Python 字符串转义破坏了 LaTeX 公式

**错误**：写入错因分析的建议字段时，普通 Python 字符串将 `\frac` 中的 `\f` 解释为换页控制字符，错题本中出现缺失反斜杠、渲染损坏的 `frac`（底层含换页控制字符）。

**触发场景**：把带 LaTeX 的建议文本写入 `workspace/records/analysis.json` 后重建错题本。

**根因**：使用普通字符串承载反斜杠命令，没有使用 raw string 或显式双反斜杠。

**修复**：改用 raw string 重写建议字段，重新生成错题本，并检查 `analysis.json` 与渲染结果。

**预防措施**：
- 脚本写入 LaTeX 时使用 raw string 或显式转义反斜杠。
- 写入后检查控制字符（特别是 `\x0c`），并 grep 目标 callout 验证公式未损坏。
