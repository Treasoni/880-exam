# 判分卡 + 卷子按 paper-XX/ 归档

判分输入从"口述 22 题状态 JSON"改为勾选判分卡：拼卷时随卷子生成一张紧凑表格（每题一行：题号/答案/对/错/不会/半会/粗心），用户做完后对照答案在状态列写 `x`，判分脚本 `grade.py --sheet` 解析勾选落库；口述 JSON（`--grading`/`--grading-file`）保留作兜底。每张卷的所有文件（卷子/答案卷/判分卡）归档到 `workspace/papers/paper-XX/` 子文件夹，避免不同日期的卷子混在一起。

**Why**：判分是最高频操作，勾选比口述快且少口误；答案直接嵌在判分卡里省去反复翻答案卷。每卷一个文件夹让一张卷的产物自包含，也避免平铺目录随时间膨胀。

**Consequences**：判分输入存在两条路径（判分卡 + JSON），但解析后共用同一判分逻辑；脚本与 `lint_content.py` 需按子目录遍历 `workspace/papers/`；wikilink 按文件名解析，子文件夹不破坏 `[[卷子-XX]]` 等链接。
