# 拼卷模型：真题结构 + 加权随机抽题

卷子规格对齐考研数二真题：选择题 10×5 分、填空题 6×5 分、解答题 6 题（约 70 分），满分 150，限时 180 分钟。章节配额按真题考频分配，难度配比 基础:综合:拓展 = 4:5:1（拓展可开关）。抽题允许重复，采用加权随机：做过次数多/近期做过 → 权重降低；判分为错/不会/半会 → 权重升高；弱章节整体升权。

**Why**：允许重复 + 加权随机使"补弱"与"抽题"共用同一套机制（仅维护每题尝试记录即可），无需另建一套错题优先逻辑。章节弱点分 = 加权错误率 + 时间衰减（不会1/半会0.6/错0.3/粗心0.15/对0），简单稳健，初期数据少也可用。

**Consequences**：题库 606 题、每卷 22 题，允许重复意味着可无限拼卷；弱章节的题目会在后续卷子中高频复现，实现"错题自动回炉"。数据模型预留 科目→章节 两级，线代题日后可直接加入拼卷池。
