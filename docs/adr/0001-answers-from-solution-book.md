# 答案来源：解析册提取，禁止 AI 生成

题目↔答案映射全部从用户提供的 880 解析册（`880/第一章到第五章解析/`、`880/第六章解析/`，已解析为 Markdown）提取。禁止 AI 生成或推断答案。

**Why**：做题本（`880/【A4紧凑版】李林880数二高数篇做题本/`）只含题目、无答案。AI 现算的答案在解答题上不可靠，一旦错误会同时污染对答案、错题本、补弱三个环节。解析册与做题本按 章→难度→题型→序号 同构对齐，可建立确定性映射。

**Consequences**：若某题在解析册中缺失或对齐失败，该题标记为"无答案"，不进入拼卷池（或在拼卷时单独警告），而不是用猜测补上。
