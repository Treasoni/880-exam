# 880 做题系统使用指南

> [!info] 这是给谁看的
> 给想用「李林 880 · 数二高数」刷题的人。你不需要懂代码——对着 AI 助手说人话，就能拼卷、判分、整理错题、看进度。

## 这套系统能干嘛

- 按考研真题模式**自动拼卷**：选择题 10×5 分 + 填空题 6×5 分 + 解答题 6 题 ≈ 150 分 / 180 分钟
- 你对照答案**判分**，系统记下每一题的情况
- 判分后**自动算分**：卷子上直接写出总分、各题型得分、本卷弱点章节
- 把做题过程发给我，**定位错因**：是哪一步开始偏的、属于哪种错，错题本里留档
- 自动整理**错题本**，每题带外部同类题链接，方便复习重做
- 随时生成**进度总览**，告诉你哪几章最弱
- 拼卷会**偏向薄弱章节**（补弱），做过的题降权、错题升权

## 开始前需要什么

- 一台能跑 Python 3 的电脑（macOS/Linux 用 `python3`，Windows 用 `py -3`）
- 推荐用 **Claude Code** 对话操作——下面的例子全是人话
- 可选：用 **Obsidian** 打开本仓库浏览卷子、错题本（生成的文件都是 Obsidian 原生笔记）

## 日常做题，五步搞定

### 1. 拼一张卷子

对 AI 说：

> 「拼张卷」

系统会在 `workspace/papers/paper-XX/` 生成一张卷子和配套**答案卷**、**判分卡**，并告诉你题号和分值。

### 2. 做完，判分

做完后打开 `判分卡-XX.md`——每道题下列着五个可勾选的状态：

> **1.** 答案：B
>
> - [ ] 对
> - [ ] 错
> - [ ] 不会
> - [ ] 半会
> - [ ] 粗心

在阅读视图**点一下**要选的格子打勾，每题只勾一个；没做的题留空。勾完告诉 AI：

> 「判分卡填好了」

系统读判分卡、记好判分，并自动做三件事：
1. 在[[卷子-01|卷子]]上写**得分与弱点**（总分 / 各题型得分 / 本卷弱点章节）
2. 刷新**错题本**
3. 刷新**进度总览**

> [!tip] 不想打勾，也可以口述
> 直接说「判分：一1对 一2错 二3不会 三1半会」也行。题号规则：**一 / 二 / 三 = 选择题 / 填空题 / 解答题**，数字 = 第几题。

### 3. 分析错题过程（可选，推荐）

哪道题当时卡壳、做错，把**你的做题过程**发给我，说：

> 「三2这题我是这么做的：…… 你看我哪步错了」

我会对照正确答案和解析，指出**第一个出错的具体步骤**、判定错因（审题失误 / 方法选择错误 / 概念定理错误 / 计算代数错误 / 步骤逻辑遗漏 / 粗心），并给一句建议。错题本里该题会留下「错因分析」记录，方便复习时回看。

### 4. 复习错题

想看错题，说：

> 「看错题本」

错题本按章节整理，重点题（不会/半会）排在前面，每题带**外部同类题链接**和错因分析。

重做后某题会了，说：

> 「重练了第 3 题会了」

错题本会自动更新复习状态（未复习 → 已重做 → 已掌握）。

### 5. 看进度

说：

> 「看进度」

系统生成进度总览：已完成多少、错题多少、哪几章最弱。**最弱章节会影响下一张卷的抽题**，越弱越常考。

## 判分五态怎么选

| 状态 | 什么时候用 | 会怎样 |
|------|-----------|--------|
| `对` | 做对了 | 不算弱点 |
| `错` | 做错，但回头能看懂 | 轻标记，进错题本 |
| `不会` | 完全没思路 | 进错题本**重点**，弱点分最高 |
| `半会` | 思路对，但没做完整 | 进错题本**重点** |
| `粗心` | 会，但看错/算错 | 轻标记 |

> [!tip] 判分越诚实，系统越准
> 判分是错题本、弱点分析、拼卷补弱的**唯一依据**。该「不会」就写「不会」，系统才会重点练它。

## 数据存在哪（了解即可）

- 卷子：`workspace/papers/paper-XX/`（拼卷后生成，每卷一文件夹：卷子 / 答案卷 / 判分卡；判分后卷子上还会写入**得分与弱点分析**）
- 判分记录：`workspace/records/attempts.json`（判分后生成，错题本和进度的唯一输入）
- 错因分析：`workspace/records/analysis.json`（分析某题后生成，渲染到错题本对应条目）
- 外部同类题关联：`workspace/records/external-links.json`（预先配置，错题本渲染用）
- 错题本：[[错题本]]（`workspace/wrong-book/`，首次判分后生成）
- 进度总览：[[进度总览]]（`workspace/preview/`，首次看进度后生成）
- 题目索引：`workspace/question-index.json`（入库时重建）

## 常见问题

> [!question] 不想用 AI，只想跑命令？
> 也行，直接跑脚本即可。常用命令见根目录 `README.md` 的「对话式命令」表。

- **Windows 报错？** 把所有 `python3` 换成 `py -3`（如 `py -3 scripts/make_paper.py`）。
- **答案准吗？** 答案全部来自解析册，**不做 AI 生成**；入库时逐题校验过。
- **错因分析是 AI 猜的吗？** 判分、答案、解析都来自原始题库，不含 AI 编造；**错因分析**这一步是 AI 基于你贴的过程 + 标准解析做的对照判断，供你参考，不等于标准答案。
- **只有高数？** 目前只有高数；数据结构预留了线代，以后可以加。
- **生成的笔记能放进 Obsidian？** 可以，卷子、错题本、进度总览都是 Obsidian 原生笔记，直接用 Obsidian 打开仓库即可。
