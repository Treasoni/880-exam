这是给谁看的 给想用「李林 880 · 数二高数 / 线代」刷题的人。你不需要懂代码——对着 AI 助手说人话，就能拼卷、判分、整理错题、看进度。

这套系统能干嘛

  • 按考研真题模式自动拼卷：选择题 10×5 分 + 填空题 6×5 分 + 解答题 6 题 ≈ 150 分 / 180 分钟
  • 你对照答案判分，系统记下每一题的情况
  • 自动整理错题本，方便复习重做
  • 随时生成进度总览，告诉你哪几章最弱
  • 拼卷会偏向薄弱章节（补弱），做过的题降权、错题升权

开始前需要什么

  • 一台能跑 Python 3 的电脑（macOS/Linux 用 python3，Windows 用 py -3）
  • 推荐用 Claude Code 对话操作——下面的例子全是人话
  • 可选：用 Obsidian 打开本仓库浏览卷子、错题本（生成的文件都是 Obsidian 原生笔记）

日常做题，四步搞定

1. 拼一张卷子

对 AI 说：

「拼张卷」

系统会在 workspace/papers/ 生成一张卷子和配套答案卷，并告诉你题号和分值。

练线代时说「拼一张线代880卷」：系统会生成独立的 la-paper-XX/、线代卷子、答案卷和判分卡，不会与高数卷冲突。

2. 做完，判分

做完后对照答案卷，把每道题的状态一次说清，例如：

「判分：一1对 一2错 二3不会 三1半会」

题号规则：一 / 二 / 三 = 选择题 / 填空题 / 解答题，数字 = 第几题。一句话说完，系统就记好了。

3. 复习错题

想看错题，说：

「看错题本」

重做后某题会了，说：

「重练了第 3 题会了」

错题本会自动更新复习状态（未复习 → 已重做 → 已掌握）。

4. 看进度

说：

「看进度」

系统生成进度总览：已完成多少、错题多少、哪几章最弱。

判分五态怎么选

状态什么时候用会怎样
对做对了不算弱点
错做错，但回头能看懂轻标记，进错题本
不会完全没思路进错题本重点，弱点分最高
半会思路对，但没做完整进错题本重点
粗心会，但看错/算错轻标记
判分越诚实，系统越准 判分是错题本、弱点分析、拼卷补弱的唯一依据。该「不会」就写「不会」，系统才会重点练它。

常用对话速查

你想做什么直接对 AI 说
拼高数卷「拼张卷」
拼线代卷「拼一张线代880卷」
判分「判分：一1对 一2错 …」
看错题「看错题本」
某题会了「重练了第 X 题会了」
看进度「看进度」
题库更新后重建索引「入库」

数据存在哪（了解即可）

  • 卷子：workspace/papers/（拼卷后生成，每张卷子带判分表）
  • 判分记录：workspace/records/（判分后生成，错题本和进度的唯一输入）
  • 错题本：错题本（workspace/wrong-book/，首次判分后生成）
  • 进度总览：进度总览（workspace/preview/，首次看进度后生成）
  • 题目索引：workspace/question-index.json（入库时重建）

常见问题

不想用 AI，只想跑命令？ 也行，直接跑脚本即可。常用命令见根目录 README.md 的「对话式命令」表。
  • Windows 报错？ 把所有 python3 换成 py -3（如 py -3 scripts/make_paper.py）。
  • 答案准吗？ 答案全部来自解析册，不做 AI 生成；入库时逐题校验过。
  • 线代怎么拼？ 说「拼一张线代880卷」，或运行 python3 scripts/make_paper.py --subject linear-algebra；线代使用独立的卷号、错题本和进度。
  • 生成的笔记能放进 Obsidian？ 可以，卷子、错题本、进度总览都是 Obsidian 原生笔记，直接用 Obsidian 打开仓库即可。
