# Workflow: zhenti-exam

考研数学**真题**（数一/数二/数三）错题系统的操作工作流。`required: no`——单步操作（收录一道真题、记一次结果、重练）直接用 `zhenti-wrong` 技能执行；本工作流用于跟踪一轮真题收录/复盘的状态，支持跨会话恢复。

## 真题原文源：先定位题号，再落库

真题**原文**在 `真题/`——**只读源**，与 `880/` 同待遇（可写 wikilink，不写入、不修改）：

```text
真题/
└── 2010-2019考研数学二真题/        # MinerU 风格的 OCR 产物
    ├── _origin.pdf                 # 41 页扫描原卷
    ├── full.md                     # ★ 唯一校对依据：题干 + 原文题号
    ├── images/                     # 题内插图（不是整页扫描图）
    └── *_content_list*.json / block_list.json / layout.json
```

> [!warning] 覆盖范围与局限（别高估它）
> - **只有 2010–2019 数二，且只有题干**：没有答案、没有解析。ADR 0001 **不受影响**——`answer` / `solution` 仍然只能来自用户提供的解析，`真题/` 里的任何文字都不能当答案用。
> - 数一 / 数三 / 2009 及以前 / 2020 及以后**未覆盖**：题号只能按用户口述落库，回读时必须**明说「题号未经原文核对」**。
> - `full.md` 是 OCR 文本：标点多为半角，**选项常与题干挤在同一行**（如 2010 的 (3)(5)）。它是**校对依据**，不是排版范本。

### 收录时的定位规矩

```bash
# 按年份定位到段，再用题干里的特征式/关键词定位题号
grep -n '^# 2010' 真题/2010-2019考研数学二真题/full.md
sed -n '949,990p' 真题/2010-2019考研数学二真题/full.md
```

1. **先定位**：在 `full.md` 里找到这道题，**以原文题号为准**——用户口述的题号只是线索，不得直接当坐标。
2. **再核对题干**：逐字比对通项、上下限、四个选项；有出入以**原文**为准。
3. **然后回读**：把定位到的题号 + 题干一并回读给用户确认，确认后才落库。
4. **转写按本册规范**：全角标点、`（　　）` 空括号、行内 `$...$` / 独立 `$$...$$`；OCR 的排版缺陷（选项挤一行）不带进记录。
5. **带图题**：把 `真题/.../images/<sha>.jpg` **复制**到 `workspace/wrong-book/images/zt-{坐标}.png`，记录里 `stem_image` 写裸名嵌入（`真题/` 只读，不写不改）。

> [!warning] 坐标错的代价（2026-09-20 实例）
> 收录 2010 数二「选择题第 5 题」（双重求和极限）时，题干图与解析册照片都自标 **(6)**，用户口述为 5；原文 `full.md` 判定 **(6)** 才是本题，`(5)` 是另一道题（`F(y/x, z/x) = 0`）。当时无原文源可查，只能靠两张图 2:1 反推。**先查原文，再落库**。

## 阶段

> [P0] 收录：按坐标查重 → 在 `真题/` 原文源定位题号并核对题干 → 回读确认 → 落 `zhenti-problems.json` 的题干与图片。
> [P1] 归档：定模块归属 + 提外部链接候选 → 用户确认 → 落库。
> [P2] 结果：记五态（对/错/不会/半会/粗心），追加到该题 `attempts`。
> [P3] 重练：只给题干，隐去答案与解析；结果回 P2。
> [P4] 渲染：重建 `真题错题本.md`（章节 + 年份索引表 + 覆盖表）并跑 lint。

## 模块归属：推导，不硬编码

真题错题按用户的**外部笔记体系**归档，模块清单**从文件系统推导**，不维护硬编码列表——外部体系增删模块时清单自动跟上：

```bash
# 高数模块：external-notes/考研数学/ 下含「错题本.md」的目录
for d in external-notes/考研数学/*/; do [ -f "$d/错题本.md" ] && basename "$d"; done
# 线代章节：external-notes/线性代数/ 下含「错题本.md」的目录
for d in external-notes/线性代数/*/; do [ -f "$d/错题本.md" ] && basename "$d"; done
```

判据是「该目录是不是一个**错题归档处**」，用 `错题本.md` 的存在性判定。当前推导结果（2026-09-19 实测）：

- **高数 7 个**：`二重积分`、`微分方程`、`高数-一元函数积分学`、`高数-一元微分学`、`高数-函数极限与连续`、`高数-多元函数微分学`、`高数-数列极限`
- **线代 6 个**：`第一章：行列式`、`第二章：矩阵`、`第三章：线性方程组`、`第四章：向量与方程组`、`第五章：矩阵相似理论`、`第六章：二次型`

> [!warning] 为什么不能硬编码
> 高数的同级目录共 9 个，其中 `0-基础知识`（纯速查表）和 `线性代数/assets` **没有** `错题本.md`，不是错题归档处。按目录名硬编码会得出「8 个高数模块」——**错的**。上面的清单是实测推导值，是判据的输出而非输入。

## 路由互斥（避免与 880-exam 抢触发词）

真题侧触发词**一律带「真题」限定**，裸词留给 880：

| 说法 | 路由到 |
| --- | --- |
| 「真题错题本」「收录一道真题」「2021 数二 真题」「真题重练」 | `zhenti-exam` |
| 「错题本」「看错题」「重练」「复习错题」（不带真题） | `880-exam` |
| 「真题」+ 880 语境（如「880 里的真题模式」） | `880-exam`（拼卷的真题模式，非本工作流） |

裸说「错题本」而语境指向真题时，**停下来问用户**，不要自行猜测路由。
