# 真题错题本

考研数学**真题**（数一/数二/数三）错题的收录、复盘与重练。**独立于 880 习题系统**：独立事实源、独立产物，不进 880 进度总览，不影响拼卷配额与弱点分。

## 与 880 的边界（先确认再动手）

| | `880-wrongbook`（880 习题） | `zhenti-wrong`（本技能） |
| --- | --- | --- |
| 题源 | `880/` 做题本 + 解析册 | `真题/` 原文源（2010–2019 数二**题干**）+ 用户提供的其余真题 |
| 事实源 | `workspace/question-index.json` | `workspace/records/zhenti-problems.json` |
| 产物 | `workspace/wrong-book/错题本.md` | `workspace/wrong-book/真题错题本.md` |
| 触发词 | 错题本、看错题、重练、复习错题 | **真题**错题、**真题**重练、收录**真题** |

- 用户裸说「错题本」「重练」而**没提真题** → 归 `880-wrongbook`，不要自作主张收进真题册。
- 语境指向真题但说法含糊 → **停下来问用户**，不要猜。
- 真题**不入** `workspace/preview/进度总览.md`，**不参与** `make_paper.py` 的配额与弱点分。

## 真题原文源（收录前必查）

真题**原文**在 `真题/`（**只读源**，与 `880/` 同待遇：只写 wikilink，不写入、不修改）。校对依据是 OCR 产物的 `full.md`：

```bash
grep -n '^# 2010' 真题/2010-2019考研数学二真题/full.md      # 按年份定位到段
sed -n '949,990p' 真题/2010-2019考研数学二真题/full.md      # 再按特征式定位题号
```

- **覆盖 `真题/2010-2019考研数学二真题/`（2010–2019 数二）**，`full.md` 给出**原文题号 + 题干**。
- **只有题干，没有答案/解析**——ADR 0001 不受影响：`answer` / `solution` 仍然只能来自用户提供的解析。
- 数一 / 数三 / 2009 及以前 / 2020 及以后**未覆盖**：题号只能按用户口述落库，回读时**明说「题号未经原文核对」**。
- `full.md` 是 OCR 文本（半角标点、选项常与题干挤在一行），是**校对依据而非排版范本**。
- 细节规则见 `.claude/workflows/zhenti-exam/workflow.md` 的「真题原文源」节。

## 事实源

`workspace/records/zhenti-problems.json` —— 唯一事实源，`真题错题本.md` 只是它的投影**产物**，**禁止手工改产物**（改了会被下次重建覆盖，且 `--check` 会报陈旧）。

```jsonc
{
  "version": 1,
  "problems": {
    "zt-2021-数二-解答3": {
      "module": "二重积分",          // 必须落在推导出的模块清单里
      "year": 2021, "paper": "数二", "no": "解答3",
      "stem": "…",                    // 题干（注意键名是 stem，不是 880 索引用的 text）
      "stem_image": "…png",           // 可选：真题原图（截图/手写照片）
      "answer": "…", "solution": "…", // 只能来自用户提供，见下「硬红线」
      "attempts": [{"date": "2026-09-19", "grade": "cannot"}],
      "review_state": "未复习",       // 未复习 / 已重做 / 已掌握
      "cause": "方法选择错误",
      "links": [{"path": "external-notes/考研数学/二重积分/错题本", "anchor": "错题03"}]
    }
  },
  "coverage": {"2021-数二": {"status": "做过", "note": "整卷过完"}}
}
```

## 步骤

1. **收录一道真题**（P0 收录 → P1 归档）：
   - **先在原文源定位题号**（覆盖到的年份/卷种）：`真题/` 里搜到这道题，**以原文题号为准**——用户口述的题号只是线索，不得直接当坐标（2026-09-20 就因按口述记「选择5」而坐标出错，原文实为 `(6)`）。原文未覆盖时按口述落库但在回读中标明未核对。
   - **核对题干**：通项、上下限、四个选项与原文逐字比对，有出入以**原文**为准；转写仍按本册规范（全角标点、`（　　）`、`$...$`），不照抄 OCR 排版。
   - 再查重，按**坐标**判：`年份 + 卷种 + 题号` 三件套相同即为同一题（不要按题干文字相似度判——同一题不同年份抄录会有出入，不同题也可能长得像）。用 `--list` 看已有记录。
   - 用户给**截图 / 手写照片**时，转写文本必须**逐字回读给用户确认**后再落库：视觉转写会认错符号（`\alpha`/`a`、下标、根号范围、上下限），转录错等于题干错。宁可让用户纠正，也不要「看起来对」就写进去。
   - 定 `module`：先跑 `--modules` 看合法值，模块清单**从外部笔记体系推导**，不要凭印象写。
   - 提**外部链接候选**给用户确认（链到 `external-notes/` 里的相关笔记/错题），确认后才写入 `links`。
2. **记一次结果**（P2 结果）：
   ```
   python3 scripts/zhenti_wrong_book.py --record zt-2021-数二-解答3=半会
   ```
   五态：`对` / `错` / `不会` / `半会` / `粗心`。结果**追加**到该题 `attempts`（保留历史，不覆盖），并联动复习状态（做对且未复习 → 已重做；**不自动**置「已掌握」，等用户确认）。
3. **重练**（P3）：
   ```
   python3 scripts/zhenti_wrong_book.py --redo zt-2021-数二-解答3
   ```
   只输出题干（隐去答案与解析）和原图；用户做完回报结果，回到第 2 步记录。
4. **更新复习状态**：
   ```
   python3 scripts/zhenti_wrong_book.py --mark zt-2021-数二-解答3=已掌握
   ```
   状态可选：未复习 / 已重做 / 已掌握。
5. **渲染**（P4）：
   ```
   python3 scripts/zhenti_wrong_book.py
   ```
6. **校验（必做，两步都要绿）**：
   ```
   python3 scripts/lint_content.py                    # 先事实源、后全部产物
   python3 scripts/zhenti_wrong_book.py --check       # 盘面产物是否已跟上事实源
   ```
   - `lint_content.py` 会**先校验 `zhenti-problems.json`** 的 `stem`/`answer`/`solution`，再校验产物：坏公式、字面 `\n`、错位 `$$` 要在事实源就被拦住，不能等它流进产物。
   - `--check` 报「产物陈旧」= 盘面文件与事实源不一致；按提示重跑生成器，**不要手工改产物**。
   - Windows 把 `python3` 换成 `py -3`。

## 硬红线

- **禁止 AI 生成或推断答案**（ADR 0001）：`answer` / `solution` **只能**来自用户提供的真题解析。没有解析就留空标「（待补）」，**绝不**自己算一个填进去——错题本里的错答案比没有答案更糟。
- **`真题/` 只读，且不含答案**：`真题/` 只给题干与题号，**一个字的答案都不能从那里取**；要图就复制到 `workspace/wrong-book/images/`，不写不改原目录。
- **`external-notes/` 全库只读引用**：只写 wikilink 指向它，**不写入、不修改**。（`external-notes/考研数学` 是指向 `/Users/zhqznc/Documents/考研复习/考研数学` 的 symlink。）
- **不收 880 / 660 / 1000 题 / 课本例题**：本册只收真题。
- **不做真题拼卷、不做套卷得分分析**：那是 `880-paper` 的领域。
- **已掌握题归档保留**：不得因最近判分为「对」而删除或隐藏记录。

## 内容规范

- 产物 frontmatter 与结构遵循 `.claude/rules/common/obsidian-content.md`；`type: 错题本`，`tags` 含 `考研数学`/`真题`/`错题本`。
- 公式定界符：Obsidian 只渲染 `$...$`（行内）与 `$$...$$`（独立）；`\(...\)` / `\[...\]` 会以原文裸露。渲染层用 `lib880.normalize_math_delimiters` 归一，写入前 `validate_text` 拒绝坏内容；补写题干/解析时直接用 `$...$`。
- 题目原图以**裸名**嵌入：`![[zt-2021-数二-解答3.png]]`，图片放 `workspace/wrong-book/images/`；题内插图可从 `真题/.../images/<sha>.jpg` **复制**过来并按 `zt-{坐标}.png` 改名（只读源不改动）。
- 改格式时：先改规则文件，再改 `scripts/zhenti_wrong_book.py`，重建后 `python3 scripts/lint_content.py` 到全绿。
